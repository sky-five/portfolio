# sky-five.web.app

Source for my personal site, live at https://sky-five.web.app/.

One static page, built on [Material Glass](https://github.com/sky-five/material-glass): a typing intro, glass panels and a photo of Theo behind everything. Static files live in `public/`, hosted on Firebase Hosting.

Deploy:

```
firebase deploy --only hosting:sky-five
```
